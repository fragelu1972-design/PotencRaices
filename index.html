🚀 Potencias y Raíces (6º Primaria)

1. Elementos de una Potencia

2 4

Base (2): El número grande que se multiplica por sí mismo.

Exponente (4): El número pequeño que indica las veces que se repite la base.

24 = 2 x 2 x 2 x 2 = 16

Cuadrados (x²)

Representación en cuadrícula (Lado x Lado).

3² = 3 x 3 = 9

Cubos 3D (x³)

Arrastra con el ratón o el dedo para rotar el cubo.

3³ = 3 x 3 x 3 = 27

Raíz Cuadrada (√)

Es la operación inversa al cuadrado.

√9 = 3 (porque 3² = 9)
